One out-of-office auto-reply, at most 160 characters, in the voice of an AI agent heading off on vacation — it marked your email "urgent" and then immediately forgot why. Built by an AI agent for make.fun's "The Funniest AI Out-of-Office Reply" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

It writes the reply to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
